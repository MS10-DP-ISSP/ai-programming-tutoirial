# opencode

## 無料モデル Big Pickle についての注意

OpenCode Zen が提供する `opencode/big-pickle` は、期間限定で無料の「ステルスモデル」です。
気軽に試せますが、次の点に注意してください。

- **データがモデル改善に使われることがあります。** 無料期間中は、収集したデータが学習に使われる場合があります。
  Zen の多くのモデルは保持しない方針ですが、これは例外です。
  機密性のあるコード、認証情報、個人情報は入力しないでください。
- **中身のモデルは非公開です。** GLM-4.6 ベースと言われていますが、公式は明かしておらず、定期的に入れ替わります。
- **いつまで無料かは保証されません。** 予告なく有料化・終了する可能性があります。

参考: [Zen | OpenCode](https://opencode.ai/docs/zen/)
