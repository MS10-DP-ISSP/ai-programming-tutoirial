環境構築

AI を用いたコーディングをする以前に，環境構築をする必要があります．

  • Git, GitHub 周り git, gh
  • Python 周り uv
  • Julia 周り julia
  • Rust 周り cargo/rustc
  • Node.js 周り node/npm/npx
  • Docker 周り docker, devcontainer
  • その他コマンド tmux, htop, btm を入れていく
  • AI Agent の導入 claude, codex, cursor, opencode

注意事項

  • Linux/WSL ユーザは管理者権限を持っているものとする(自分のマシンとか).
  • macOS ユーザは Homebrew を使用する.
  • Windows ユーザは Winget を使用する.
    • Windows 11 であれば PowerShell を開けば winget が使える.
    • wt で Windows Terminal を開けば PowerShell が使える.
  • Nix のようなパッケージマネージャを知っている人はこの講義の対象者ではないので勝手に環境構築をして遊ぶこと．
  • すでに環境構築ができている方は読み流してよい．あくまでも参考程度に読んでほしい．
  • Windows 環境で開発環境を整えるのは茨の道であるので，可能であれば Linux/WSL を使用すること．

WSL を導入する方法

Windows 11 であれば PowerShell を開けば WSL を経由することで Linux 環境を構築することができる．

wsl.exe --install Ubuntu-24.04

PC 自体を再起動してから Ubuntu-24.04 をインストールする．

Git のインストール

バージョン管理システムである Git をインストールする．コマンドは git. なお，コミットメッセージを手動で書いたり，ファイルの行単位でコミットの操作を行う場合には tig を使用すると便利である．

Linux/WSL

sudo apt-get install git tig

macOS

brew install git tig

Windows

winget install --id Git.Git --source winget

Windows ユーザは上記のコマンドで自動的に tig もインストールされる．

コミットする際には誰が行ったかを記録するメタデータを設定する必要がある．そのために名前とメールアドレスを設定する必要がある．

git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

GitHub CLI gh のインストール

Git で管理されているリポジトリをホストするサービスとして GitHub がある．GitHub ではリポジトリを管理するための CLI が提供されている．コマンドは gh. インストール方法は https://cli.github.com/ の案内に従う．

Linux/WSL

(type -p wget >/dev/null || (sudo apt update && sudo apt install wget -y)) \
    && sudo mkdir -p -m 755 /etc/apt/keyrings \
    && out=$(mktemp) && wget -nv -O$out https://cli.github.com/packages/githubcli-archive-keyring.gpg \
    && cat $out | sudo tee /etc/apt/keyrings/githubcli-archive-keyring.gpg > /dev/null \
    && sudo chmod go+r /etc/apt/keyrings/githubcli-archive-keyring.gpg \
    && sudo mkdir -p -m 755 /etc/apt/sources.list.d \
    && echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/githubcli-archive-keyring.gpg] https://cli.github.com/packages stable main" | sudo tee /etc/apt/sources.list.d/github-cli.list > /dev/null \
    && sudo apt update \
    && sudo apt install gh -y

macOS

brew install gh

Windows

winget install -e --id GitHub.cli --source winget

gh auth login で GitHub アカウントと連携する

これで，GitHub のサービスを CLI から利用することができる．

GitHub のセキュリティ向上のために二要素認証を設定するのが望ましい．近年はパスキーを使う方法もサポートされている．

Python のインストール

MCPサーバを体験するために Python をインストールする．多くの OS ではデフォルトで Python がインストールされているが，pip install ... のようにナイーブに実行するとシステム環境用の Python 環境を汚してしまう恐れがある．そこで Python の仮想環境を作成するために uv を使用する．

Linux/WSL

sudo apt-get install curl
curl -LsSf https://astral.sh/uv/install.sh | sh

macOS

brew install curl
curl -LsSf https://astral.sh/uv/install.sh | sh

Windows

winget install --id Astral-sh.uv --source winget

下記のように使用することができる．

$ mkdir example
$ cd example
$ uv init
$ uv add numpy
$ uv run <your-script.py>

Julia のインストール

Julia は高性能な数値計算を行うための言語である．インストール方法は https://julialang.org/downloads/ の案内に従う．

Linux/WSL/macOS

$ curl -fsSL https://install.julialang.org | sh

Windows

PS> winget install --name Julia --id 9NJNWW8PVKMN -e -s msstore

下記のように使用することができる．

$ julia -e 'using Pkg; Pkg.generate("MyPkg.jl")'
$ cd MyPkg.jl
$ julia --project -e 'using MyPkg; println(MyPkg.hello("Julia"))'
Hello, Julia

なお export JULIA_PROJECT=@. を設定すると --project オプションを省略することができる．

Rust のインストール

Linux/WSL/macOS

https://www.rust-lang.org/tools/install の案内に従う．

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Windows

https://learn.microsoft.com/ja-jp/windows/dev-environment/rust/setup?tabs=winget の案内に従う．

管理者権限でPowerShell を開き，以下のコマンドを実行する．

PS> winget install -e --source winget --id Microsoft.VisualStudio.2022.BuildTools `
  --accept-source-agreements `
  --accept-package-agreements `
  --override "--wait --passive --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"

通常のPowerShell で以下のコマンドを実行する．

PS> winget install Rustlang.Rustup --source winget

動作確認

$ cargo new hello-world
$ cd hello-world
$ cargo run --release
cargo run --release
   Compiling hello-world v0.1.0 (path/to/your-workspace/hello-world)
    Finished `release` profile [optimized] target(s) in 1.38s
     Running `target/release/hello-world`
Hello, world!

src/main.rs を編集することでコンパイルして実行することができる．

Node.js のインストール

NodeJS は JavaScript の実行環境であり，npm を使用することで JavaScript のパッケージを管理することができる． 様々なツールは npm 通してインストールすることを要請されることもあるので存在ぐらいは覚えておくとよい．

インストール方法は https://nodejs.org/ja/download/ の案内に従う．

Linux/WSL/macOS

# nvmをダウンロードしてインストールする：
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.7/install.sh | bash
# シェルを再起動する代わりに実行する
\. "$HOME/.nvm/nvm.sh"
# Node.jsをダウンロードしてインストールする：
nvm install 24
# Node.jsのバージョンを確認する：
node -v # "v24.21.0"が表示される。
# npmのバージョンを確認する：
npm -v # "11.19.0"が表示される。

Windows

PS> winget install --id OpenJS.NodeJS.LTS --source winget
PS> node -v
PS> npm -v

その他ベンチコマンドのインストール

これはこのページを書いた人の趣味であり，必須ではない．CPUの使用率を確認する際は htop, btm, macmon を使用するとよい． macmon は macOS 専用のツールであり, GPU 使用率を監視するために便利である．

rg は ripgrep の略であり，ファイル内を検索するためのツールである．grep の代わりとして使われる．Agent は rg を使うことが多いので入れておくとよい．

tmux はターミナルマルチプレクサの役割を果たす． SSH 接続先のセッション管理に便利である．

Linux/WSL/macOS

sudo apt-get install tmux htop ripgrep

macOS

brew install tmux htop rg macmon

Windows

参考: psmuxでWindows 11＋PowerShellでtmux by @charon に従い，tmux をインストールする．

PS> winget install psmux --source winget

Windows は htop の代わりに btm を使用する．

PS> winget install Clement.bottom --source winget

Docker のインストール

Docker (docker)

Codex はユーザからの許可をバイパスするオプションを備えている．たとえば --yolo といったオプションだ．このようなオプションは便利だが 原理的には rm -rf / のような危険なコマンドの実行も許すことになる．このような状況を防ぐためにサンドボックス環境を使うのが望ましい．たとえば Docker が提供するコンテナはマウントするファイルを制御することで制限された範囲で AI Agent を行動させることが可能である．

OS に応じてインストールすること:

  • Install Docker Desktop on Mac
  • Install Docker Engine on Linux(Ubuntu)
  • Install Docker Desktop on Windows

動作確認は下記のコマンドでできる:

$ docker run --rm hello-world

Windows ユーザ向けの注意事項

  1. Docker Desktop を開く
  2. Settings にいく（Ctrl＋，）でジャンプできる
  3. Resource にいく．下記のようにチェックを入れる．

Dev Container のインストール

Dev Container は Docker コンテナを使って環境を構築するためのツールである．.devcontainer/devcontainer.json を用意することで環境を構築することができる．本講義では handouts/devcontainer ディレクトリ以下にある環境をアクティベートする際に使用する．

Cursor または VS Code の拡張機能から Dev Container をインストールする．

https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-containers

CLI 版もある (Optional)

https://code.visualstudio.com/docs/devcontainers/devcontainer-cli を参考にすること．CLI は npm を使用してインストールする．

Linux/WSL/macOS

$ curl -fsSL https://raw.githubusercontent.com/devcontainers/cli/main/scripts/install.sh | sh

PATH 環境変数を次のように編集する

export PATH="$HOME/.devcontainers/bin:$PATH"

Windows ユーザは npm を使用してインストールする．

$ npm install -g @devcontainers/cli

AI Agent の導入

どれか好きなのをインストールすれば良い．基本的に有料プランを前提とするので無料版に関しては説明しない．20ドルプランがあれば十分である．

Claude Code

https://code.claude.com/docs/en/overview を参考にすること

Linux/WSL/macOS

curl -fsSL https://claude.ai/install.sh | bash

Windows

irm https://claude.ai/install.ps1 | iex

OpenAI Codex

https://learn.chatgpt.com/docs/codex/cli#getting-started を参考にすること

Linux/WSL/macOS

curl -fsSL https://chatgpt.com/codex/install.sh | sh

Windows

powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

OpenCode

https://opencode.ai/v2/docs を参考にすること

Linux/WSL/macOS

curl -fsSL https://opencode.ai/v2/install | bash

Windows ユーザは Download a standalone CLI binary for your platform. からバイナリをダウンロードして使う

Cursor

https://cursor.com/download からダウンロードしてインストールする．

VS Code

https://code.visualstudio.com/download からダウンロードしてインストールする．
